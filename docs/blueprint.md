# **App Name**: PrimaryReads

## Core Features:

- Book Catalog: Display a catalog of available primary school books.
- Google Drive Integration: Links to books stored in Google Drive.
- Search and Filter: Allow users to search for books by title, subject, or grade level.
- Content Summary: Use an LLM to provide a summary for the educational books.

## Style Guidelines:

- Primary color: Cheerful blue (#64B5F6) to convey trust and knowledge.
- Background color: Soft, light gray (#F5F5F5), nearly white, to keep things bright and readable.
- Accent color: Energetic yellow (#FFEB3B) as a contrast to blue, used to highlight important interactive elements.
- Body and headline font: 'PT Sans', a modern and humanist sans-serif, will provide a balance of approachability and legibility for children and educators.
- Use clear, age-appropriate icons to represent book genres and categories.
- A clean, organized layout with clear visual hierarchy to improve user navigation and readability.
- Subtle animations or transitions for loading content to keep the user engaged.
